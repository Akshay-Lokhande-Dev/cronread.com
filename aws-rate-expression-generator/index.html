AWS EventBridge Rate Expression Generator

Create a valid AWS rate() expression for fixed schedules.

rate(5 minutes)

When should I use rate instead of cron?

Use rate expressions for simple repeating intervals such as every 5 minutes or every 2 hours. Use cron expressions for calendar schedules such as every weekday at 9 AM.
