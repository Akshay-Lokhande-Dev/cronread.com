About CronRead

CronRead is a free, browser-based toolkit for developers who work with cron expressions, timestamps, and other everyday scheduling and encoding tasks. We built it because most cron tools online only go one way — you paste a cron string and get an explanation, but you can't go the other way around, and you rarely get ready-to-use snippets for the platform you're actually deploying to.

CronRead lets you type a cron expression, a macro like @weekly, or even plain English like "every weekday at 9am" — and instantly get the equivalent cron string, a human-readable explanation, upcoming run times in your own timezone, and copy-paste snippets for AWS EventBridge, Kubernetes CronJobs, Terraform, GitHub Actions, and the AWS CLI.

Why we built it

Cron syntax hasn't changed much in decades, but the platforms that use it have multiplied — AWS, Kubernetes, GitHub Actions, and traditional Linux crontabs all have their own quirks (like AWS EventBridge's 6-field format and its day-of-month/day-of-week rule). We wanted one place to write, validate, and convert a schedule without digging through five different sets of docs.

How it works

CronRead runs entirely in your browser. There's no account, and the core tools keep working even without an internet connection once the page has loaded.

What else is on the site

Beyond the cron tools, CronRead also hosts a small set of related developer utilities — a Unix timestamp converter, a JWT decoder, a YAML/JSON converter, a Base64 encoder, and a SQL explainer — along with guides on cron syntax, AWS EventBridge, and platform-specific scheduling examples.
