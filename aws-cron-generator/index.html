AWS EventBridge Cron Expression Generator

Generate and validate AWS EventBridge cron() expressions. AWS uses six fields: minutes, hours, day-of-month, month, day-of-week and year.



AWS cron examples

  • 0 9 ? * MON-FRI * — weekdays at 9:00 UTC
  • 0 0 1 * ? * — first day of every month
  • 0 12 ? * MON#1 * — first Monday at noon

Cron or rate expression?

Use rate(5 minutes) for fixed intervals. Use cron(...) when you need an exact calendar schedule.

Important AWS EventBridge rule

Day-of-month and day-of-week cannot both be concrete values. Use ? in one of those fields when the other field is specified.
